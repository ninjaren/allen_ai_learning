# 我的技能樹

把我學過的技能整理成一棵技能樹的學習網站。每個節點是一則課文，開頭附官方文件連結，內容用白話說明，並盡量說清楚「為什麼這樣做」。

這是純靜態網站：HTML、CSS、JavaScript，沒有後端，也沒有建置步驟。

## 內容

- **AI**：LLM 基礎、API 使用、評測、Prompt 工程、常見任務模式等。
- **常用框架**：NumPy、pandas、Gradio、Streamlit、SQLAlchemy、pytest 等。
- **實作專案**：用自己的釣魚資料，一步一步做出一個「釣魚助理」，共六個專案加一頁總覽（51 課）：
  1. 釣魚日誌整理器（結構化輸出）
  2. 釣魚知識問答（RAG：切塊、BM25、嵌入、混合檢索）
  3. 釣點顧問 Agent（工具呼叫與護欄）
  4. 直播看車流（OpenCV 背景相減、YOLO、官方車速驗證）
  5. 評測與優化（開發集與留存集、用量與花費、A/B 比較）
  6. 作品集整合上線（FastAPI、安全守衛、日誌、Docker）

  LLM 層寫成可替換供應商的介面，以 Claude 與 Gemini 為例。課文裡的程式碼都附有詳細註解。

## 檔案結構

```
index.html        頁面入口
style.css         樣式
app.js            技能樹與課文的畫面邏輯
data.js           技能樹的結構（分支、階段、節點）
lessons/          每一課的內容，refs.js 放各課的官方連結
```

## 在本機開啟

用本機伺服器開，不要直接雙擊檔案（`file://` 下腳本可能無法正常執行）：

```bash
python -m http.server 8765
```

然後在瀏覽器開啟 `http://localhost:8765/`。

## 新增或修改課文

1. 在 `lessons/` 寫課文，內容是 `window.LESSON` 的一組區塊（文字、程式碼、清單、表格、提示等）。
2. 在 `data.js` 把課文掛到對應的節點。
3. 在 `lessons/refs.js` 補上該課的官方文件連結。
4. 在 `index.html` 加上新檔案的 `<script>`。

行內標記有限制：粗體內不能有星號，程式碼區塊內不能有反引號或 `${`。

## 部署

任何靜態網站託管都可以，例如 Cloudflare 的靜態資源託管：把整個資料夾當成輸出目錄，不需要建置指令。

## 需要先知道的事

- 實作專案裡的程式碼，邏輯都在本機驗證過（假模型與假伺服器、自動測試），但**沒有用真實的 Claude 或 Gemini 金鑰完整跑過**。
- 專案 6 的 Docker 檔案**沒有實際建置過**，也沒有實際部署。
- 專案 4 的實測結果：影像指標無法跨攝影機預測壅塞，所以最終設計以官方車速為主、影像為輔。
- 專案 5 的調參用的留存集只有 7 題，無法確認改善是否真的成立。

詳細說明見網站「實作專案」的「總覽」頁。
